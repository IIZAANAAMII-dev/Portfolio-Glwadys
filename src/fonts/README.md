# Local font provenance

Unmodified WOFF2 distributions from Fontsource 5.3.0 (npm registry):
- @fontsource-variable/bodoni-moda: Latin `standard` (weight + optical-size axes).
- @fontsource-variable/inter-tight: Latin weight axis.
- @fontsource/kalam: Latin regular 400.
- @fontsource-variable/noto-sans-kr: original unicode-range CSS and WOFF2 subsets; browser loads only glyph ranges it needs, no preload.

Each family's SIL Open Font License and copyright notice are retained in its LICENSE file. Original families and styles are preserved. Latin subsets include French accents and œ. This removes Google Fonts network access from builds; no third-party requests at runtime. No external package scripts were executed. The CSS and binaries are vendor assets, not generated campaign imagery.
