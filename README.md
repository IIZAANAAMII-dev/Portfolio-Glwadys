# Portfolio Glwadys — Greenfield V2

Cinematic, editorial, one-scroll portfolio.

## Structure

- `src/app/` — Next.js app router.
- `src/components/` — React components.
- `src/lib/` — GSAP, Lenis, motion utilities.
- `src/styles/` — globals, tokens.
- `public/` — real assets.
- `docs/` — creative direction and storyboard.

## Commands

```
npm install
npm run dev
npm run build
```
